## 🚀 Features

### 👤 User Management

* User registration with email and password validation
* Secure login authentication
* Error handling for invalid credentials

### 🗺️ Parking Spot Discovery

* Google Maps integration for real-time parking visualization
* Display of available parking locations
* User location tracking
* Distance and route information to selected parking spots

### 🅿️ Parking Reservation System

* Reserve selected parking spots
* Release parking spots upon departure
* Real-time parking availability updates
* Parking confirmation alerts

### 📊 Parking History & Records

* View stored parking records
* Access historical parking data
* Firebase database integration for data storage

### 🎙️ Voice Navigation

* Speech recognition for hands-free page navigation
* Voice-controlled access to app sections

### ⚙️ Settings Management

* Language selection support
* User interface customization
* Preferences management
